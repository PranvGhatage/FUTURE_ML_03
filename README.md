# Resume / Candidate Screening System

A Machine Learning project that analyzes resumes, extracts skills, compares candidates with a job description, and ranks them based on job fit.

## Features

- Resume text cleaning and preprocessing
- Technical skill extraction
- Job description analysis
- Resume–job similarity using TF-IDF and Cosine Similarity
- Candidate skill matching
- Missing skill identification
- Candidate ranking
- Ranking and skill-match visualizations

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- NLTK
- Matplotlib
- Jupyter Notebook

## Scoring

**Final Score = 70% Resume-Job Similarity + 30% Skill Match**
